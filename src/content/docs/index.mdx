## Quick Start

Get your site running in about 10 minutes:

```bash
# Clone the free starter theme (public repository)
git clone https://github.com/vincentheimann/astro-swiss-free-starter-theme.git
cd astro-swiss-free-starter-theme

# Install dependencies
npm install

# Start development server
npm run dev
```

Then customize your brand colors, company info, and content. **[Follow the complete guide →](/getting-started/)**

<Aside type="note" title="Free & paid theme">
  These docs cover the whole **Astro Swiss theme family**. Both themes ship **French, German and English**. The Quick Start above uses the **free starter theme**. Bought the **paid theme**? Extract the purchased ZIP and set it up with your AI agent — or one command by hand — via the [Agent Setup guide](/guides/agent-setup/); everything else in these docs applies to both.
</Aside>
